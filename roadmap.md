# Atei DevOps — build roadmap

## Phase 1 (core loop)
- [ ] Cloud backend + schema (users/profiles, roles, brands, projects, tasks, daily logs, log items, photos, attendance, approvals, comments, notifications)
- [ ] RLS + role helper (has_role)
- [ ] Design system (Graphite Ops Grid tokens)
- [ ] Auth page (email + password)
- [ ] App shell with role-scoped nav
- [ ] Employee: dashboard, clock in/out (server time + GPS), my tasks, daily log with photos
- [ ] Manager: dashboard, task assignment, approvals
- [ ] Super admin: executive overview, users, brands/projects
- [ ] Notifications
- [ ] CSV export

## Phase 2 (later)
- Analytics, geofencing, scheduled reports, WhatsApp/SMS, offline queue, audit log viewer
